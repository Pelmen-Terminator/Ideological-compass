 Структура
- `index.html` — основной HTML-шаблон
- `style.css` — стили (тёмный сайдбар, светлая область чтения)
- `data.js` — все данные об идеологиях (150+ идеологий)
- `app.js` — логика рендеринга и маршрутизации

Технологии
- Чистый HTML/CSS/JavaScript без внешних зависимостей
- Шрифты Google Fonts: Fraunces, Source Serif 4, IBM Plex Mono
- Маршрутизация через хэши URL (`#/ideology-id`)
- Адаптивный дизайн с touch-оптимизацией
