# Идеологический Компас

**Версия 7.0**

## ⚠ Важное предупреждение

Данный сайт является **справочно-информационным** ресурсом. 

Он **НЕ пропагандирует**, не одобряет и не поддерживает ни одну из представленных идеологий. Все описания носят **академический, нейтрально-информационный** характер.

Некоторые идеологии, представленные здесь, могут быть **опасными, дискриминационными** или противоречащими общечеловеческим ценностям. Сайт **не рекомендует** их к принятию или реализации.

**Цель проекта** — образовательная: дать объективное представление о многообразии политических учений.

**Обозначения:** ⚡ — радикальные идеологии, ⚠ — экстремистские идеологии (запрещены или осуждаются).

## Структура

- `index.html` — основной HTML-шаблон
- `style.css` — стили с поддержкой тем и размеров
- `data.js` — все данные об идеологиях (150+)
- `app.js` — логика рендеринга, маршрутизации и настроек

## Технологии

- Чистый HTML/CSS/JavaScript
- Шрифты Google Fonts: Fraunces, Source Serif 4, IBM Plex Mono
- Маршрутизация через хэши URL (`#/ideology-id`)
- Адаптивный дизайн с touch-оптимизацией
- Сохранение настроек в localStorage
